# Full-Stack Task Manager (Node.js + Express + Supabase)

A lightweight full-stack CRUD application built with Node.js, Express, Supabase (PostgreSQL), and Vanilla HTML/CSS/JS.

## Features
- Create, Read, Update, and Delete tasks.
- Persistent data storage using Supabase.
- Clean REST API architecture built with Express.
- Responsive user interface.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** Supabase (PostgreSQL)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Version Control:** Git, GitHub
